# Research skill

Use this skill when the user asks for in-depth research, comparisons, or literature-style summaries.

## Steps

1. Create a short research plan (3–5 bullets) and save it to `/notes/plan.md`
2. Run targeted web searches — prefer primary sources and official docs
3. Save key excerpts to `/notes/sources.md` with URLs
4. Synthesize into a final answer; cite every major claim
5. If conclusions are uncertain, say so explicitly

## Output format

- **Summary** (2–3 sentences)
- **Key findings** (bullets)
- **Sources** (linked list)
